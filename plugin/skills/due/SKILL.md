# 复习到期卡

```
node ${CLAUDE_PLUGIN_ROOT}/dist/coach.mjs kb --due
```

没有到期卡时就一句话结束：「今天没有该复习的」。**不要**顺势列全部卡片、
不要建议他现在多复习几张 —— 复习节奏一乱，这功能就会被关掉。

## 有卡的时候

一张一张来，**不要一次把所有卡全贴出来**。每张卡走完这四步再进下一张：

1. **先只给标题和证据**，把 `## 我自己的表述` 那节**盖住**：
   ```
   node ${CLAUDE_PLUGIN_ROOT}/dist/coach.mjs kb --show <id>
   ```
   但**别直接把输出贴给他** —— 里面就有答案。先只念标题 + `## 证据` 那几行，然后问：
   > 「<标题>」这条。你还记得当时为什么吗？

2. **等他说。** 他答了才把 `--show` 的完整输出贴出来对照。
   对照时只说差异：「你记的是 X，当时写的是 Y」—— 不要评价他答得好不好。

3. **让他自己给这一条定档**，就一次问一句：
   > 这条你自己说：稳了、模糊，还是没想起来？

   他说哪个词，你就用哪个词 —— 一个字都不要改。
   他如果换了个说法（「想不起来了」），就问一句「那算没想起来，对吗？」，
   确认后再用那个词。**你绝不替他选。**

4. **把他给的那个词原样传进去**（这是这次复习唯一的写动作）：
   ```
   node ${CLAUDE_PLUGIN_ROOT}/dist/coach.mjs kb --reviewed <id> --recall <他说的那个词>
   ```
   把 CLI 打出来的那一行**原样**贴给他 —— 里面有下次复习的日期。

## 他没想起来的时候

「没想起来」照第 4 步先记下来（那是他说的，不是你判断的）。记完再对他说：
> 这条你刚才没想起来。要么当时那句话写得不够像你自己说的，
> 要么它本来就不值得记 —— 要重写一句，还是直接把它删了？
两条路都行。**别劝他留着。**

## 复习完

如果他想改自己那句话，用 `save` 覆盖同一个 id（见 `save` skill），
不要新建一张卡 —— 新卡会把旧卡变成孤儿，`index.md` 里会出现两条讲同一件事的。
已经记下的档位不用回滚：那次复习确实发生过。

## 别做的事

- 不要自己给他出题、不要编造 `--show` 之外的内容。
- **复习基本只读。唯一的例外是记录他刚才给自己的那个档**：`kb --reviewed <id> --recall <词>`。
  除此之外一个字都不许写 —— 不要 `--confirm`、不要改状态、不要动卡片正文，
  尤其不要碰 `## 我自己的表述` 那节。
- **档位只有一个来源：他刚才亲口说的那个词。** `--recall` 里必须原样传他的话，
  不许你判断他答得怎么样，不许把「差不多吧」翻译成「稳了」，不许因为你看他
  答得不错就替他升级。他要是没明确说，就问一句，别猜 —— 猜错一次，
  这条时间线就再也不可信了。
- 不要因为一天有 5 张到期就一次全塞给他。他不耐烦了就会再也不敲这个命令。
