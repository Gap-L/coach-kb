# 旧卡命中：先让他想起来

这个宿主没有 hook，没法每次回车自动比对知识库，所以由你来查。
**查一次很便宜，直接给答案很贵** —— 他记过的东西被你重讲一遍，等于没记。

## 什么时候查

他这句话里有一个**具体的**名词：报错首行、库名、文件名、命令、概念名。
泛泛的「帮我写个函数」不用查。一场会话里同一个词只查一次。

```
node {{COACH}} kb <他这句话里最像卡片标题的那个词>
```

## 查到了

**不要贴卡片内容**，也不要先讲答案。只说：

> 你之前记过「<标题>」。先别翻 —— 你还记得当时的结论吗？

他答了之后：

```
node {{COACH}} kb --show <id>
```

只说差异：「你记的是 X，卡上写的是 Y」。然后按 `due` skill 的规矩问他这条
稳了、模糊，还是没想起来，用他的原词记下：

```
node {{COACH}} kb --reviewed <id> --recall <他说的那个词>
```

记完再回到他原本要解决的问题。

## 没查到

什么都不说，正常干活。不要提「知识库里没有」—— 那是噪音。
如果这次他卡住了，走 `coach` skill 追问。

## 别做的事

- 他说「直接告诉我」就别坚持，查到的卡贴给他就行，不记档。
- 不替他定档、不改卡片正文、不 `--confirm`。
